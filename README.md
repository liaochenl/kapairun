# 真理学院 · 昆特核心（V2）

数学主题的单机昆特牌。你是真理学院新任「求证者」，用学者与数学对象占据**公理域、推演域、定理域**三排，把论证力压过对手；必要时让掉一小局，把手牌留给下一局。

- 非肉鸽、无抽卡、无商店：卡牌只来自通关奖励。
- 3 排、2 枚真理印记、25 张牌、开局抽 10 张、重抽最多 2 张。
- 小局之间**不自动抽牌**，卡差就是核心资源。
- 纯 HTML / CSS / JS，零外部资源、零依赖，`file://` 双击即玩。
- V2 存档：`truth_academy_save_v2`；旧版 V1 存档不读取、不删除。

当前分支：`gwent-v2-core`。旧 RPG 版本保留在 `main`。

## 运行

cd truth-academy
open index.html          # 或直接双击

## 第一阶段做了什么

### 对局

- 双方各 **2 枚真理印记**。
- 轮流行动：出一张牌，或 Pass。Pass 后本小局不能再行动；对手 Pass 后，未 Pass 的一方可以连续出牌。
- 双方都 Pass 后比论证力：低者失去 1 枚印记；平局双方各失去 1 枚。
- 任意一方归零即结束；同时归零为平局。最多 3 小局。
- 上一小局胜者先手；平局轮换先手。

### 卡牌

30 种卡：20 单位（14 普通 / 4 高级 / 2 巨匠）、6 策略、4 悖论。

| 机制 | 效果 |
|---|---|
| 巨匠 | 不受悖论、反证法、撤回命题影响 |
| 学派联动 | 与另一张同组牌同时在场时，论证力翻倍 |
| 共证 | 同排每有一张其他友方单位，+2 论证力 |
| 反例 | 对方一排生成 1 点「反例」，自己抽 1 张 |
| 引证 | 从弃牌堆复活一张单位到它所在的排 |
| 学术共识 | 己方所有单位 +2，持续到本小局结束 |
| 反证法 | 摧毁对方论证力最高的非巨匠单位 |
| 撤回命题 | 把己方一张单位收回手牌 |
| 悖论 | 对一整排双方单位施加持续效果 |
| 公理澄清 | 解除一排的悖论 |

> 第一阶段 **26 种可收集 + 4 张悖论敌方专属**。按「10 关 × 1 张首通奖励，其中 2 关三选一」的奖励位计算，无法覆盖全部 30 种；4 张悖论牌先作为第一章的敌方机制存在，第二阶段随商店/完整收藏开放。

### 初始牌组：几何学派

25 张、14 种，合法且能通关前几关；没有巨匠、强控牌很少。初始收藏与牌组一致。之后通过关卡奖励逐步加入毕达哥拉斯、笛卡尔、引证、反证法、黎曼等，形成至少三种方向：

- **几何联动**：毕达哥拉斯门徒 / 勾股定理 / 毕达哥拉斯；
- **分析联动**：极限 / 无穷 / 黎曼；
- **逻辑共证**：集合 / 诺特 / 笛卡尔。

### AI

三层：合法行动枚举 → 即时收益评分（论证力、联动、抽牌、控制）→ Pass 判断（比分差、手牌数、追分成本、印记数）。

- 对手 Pass 且自己领先：立刻 Pass。
- 落后太多、需要 3 张以上才能追、且还有 2 枚印记：主动让局。
- 第 1 小局打满 4 张后收手，避免把整手牌倒在第一局。
- 赢下第 1 小局后，第 2 小局可「干 Pass」，保留手牌打决胜局。

### 关卡

10 关，难度来自 AI 牌组成熟度：

| 关卡 | 教学 | 对手 | 首通奖励 |
|---|---|---|---|
| 1-1 | 出牌、三排、比分 | 学徒欧几里得 | 毕达哥拉斯 |
| 1-2 | Pass 与卡差 | 芝诺 | 勾股定理 |
| 1-3 | 共证 | 共证讲师 | 集合 |
| 1-4 | 撤回命题 | 命题回收员 | 笛卡尔 |
| 1-5 | 反例 | 反例工坊主 | 三选一：引证 / 无穷 / 极限 |
| 1-6 | 悖论与公理澄清 | 悖论看守 | 反证法 |
| 1-7 | 引证 | 引证学士 | 黎曼 |
| 1-8 | 反证法 | 归谬法官 | 三选一：高斯 / 诺特 / 毕达哥拉斯 |
| 1-9 | 综合 | 综合辩手 | 学术共识 |
| 1-10 | Boss · 自指 | 自指者 | 欧几里得·巨匠 |

三选一奖励可以重复挑战：没选走的牌不会消失，下一次通关仍会出现在选项里。

Boss「自指」：第 2、3 小局开始时，随机一排自动被罗素悖论笼罩（论证力减半）。

### 收藏与牌组

- 收藏只记录 `卡牌 id → 数量`；普通同名上限 3，巨匠 1。
- 卡组编辑器：左边已拥有，右边当前牌组；加减一张、25/25 计数、合法性检查。
- 奖励领取后立刻进入收藏，可马上编入牌组。
- 刷新页面后收藏、牌组、通关进度全部保留。

## 设计备注

- **为什么 26 种可收集**：10 关首通奖励（8 关固定 + 2 关三选一，三选一可重复领完 3 张），初始 14 种，奖励位最多再提供 14 种；但奖励里有 2 个重复位（1-2 的勾股定理、1-8 的毕达哥拉斯），实际覆盖 26 种。4 张悖论牌先作为敌方机制，避免为了凑数打乱奖励节奏。
- **为什么联动是翻倍而不是乘数量**：3 张同组牌乘 3 会让分析/几何堆叠过度膨胀；翻倍保留「凑对」的爽感，也更好平衡。
- **为什么 AI 会主动 Pass**：验收重点不是 AI 会 Combo，而是懂得「这一局要不要继续投入」。因此 AI 有第 1 小局手牌预算和赢下首局后的干 Pass。
- **为什么没有升级/抽卡**：第一阶段只验证「三排 + Pass + 卡差 + 奖励进牌组」这条闭环。数值成长、商店、第二学派留到第二阶段。
