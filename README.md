# 真理学院 · 悖论裂缝

数学主题的单机收集养成抽卡 Demo。你是真理学院新任「求证者」，从无限集中召回历史上的学者，用公式接续公式、合成定理，修复被悖论侵蚀的证明。

- 非肉鸽：没有随机地图、没有单局重置；角色、等级、星章与图鉴永久保留。
- 3 人小队，每回合共享 3 点行动力。
- 公式带标签；同一回合里，两名**不同学者**按标签接续，就能合成一条「定理」。
- 黑板粉笔视觉，纯 HTML / CSS / JS，零外部资源、零依赖。

## 运行

直接双击 `index.html` 即可（支持 `file://`）。存档写入浏览器 `localStorage`，键名 `truth_academy_save_v1`。

也可以起一个本地静态服务：

```bash
cd truth-academy
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 怎么玩

- **行动力**：每回合 3 点。公式 1 点，公理 2 点。
- **公式**：每名学者有 2 张公式，每张每回合限用一次。公式上的标签（极限、级数、同余、归纳、对称、公理、作图、坐标、比例、概率）决定它能接出什么。
- **定理**：同一回合内，用两名不同学者的公式按已知配方接续，自动触发定理，不额外消耗行动力。技能按钮上的金色「可续接」标签就是提示。
- **公理**：每名学者的绝技，消耗 2 点行动力，使用后进入冷却。
- **方法克制**：公式分为演绎、计算、构造。命中敌人弱点伤害 +50%，被抗性抵挡则 -30%。
- **悖论护盾**：Boss 的护盾只被定理伤害削减；护盾存在时普通公式伤害减半。
- **星章**：通关 1 星；无人倒下 +1 星；在指定回合内完成 +1 星。新的星章会额外给灵感。
- **养成**：图鉴 → 学者 → 详情，消耗讲义升级；达到上限后消耗手稿突破；抽到重复学者会转为顿悟（每层 +6% 生命/攻击/防御）。
- **抽卡**：3200 灵感起步，单抽 160 / 十连 1600。十连至少一名 SR；SSR 硬保底 40 抽（30 抽后概率递增）。无内购，灵感只来自课程与星章。

快捷键：`1/2/3` 选择学者，`Q/W/E` 使用两张公式与公理，`空格` 结束回合，`Esc` 取消目标 / 关闭弹窗。

## 内容量

| 项目 | 数量 |
|---|---|
| 学者 | 8 名（2 SSR / 3 SR / 3 R） |
| 公式 | 16 张 |
| 公理 | 8 条 |
| 定理配方 | 14 条 |
| 悖论 | 10 种（含 Boss 罗素悖论） |
| 课程 | 第一章 10 关 |
| 初始队伍 | 欧几里得 / 毕达哥拉斯 / 帕斯卡 |

所有 14 条定理都能用现有 8 名学者组合出来。初始队伍已经可以合成「勾股定理」「相似三角形」「三等分角」，其余配方需要抽卡与编队尝试。

## 测试

```bash
cd truth-academy
npm test          # 规则测试：战斗、定理、状态、Boss、抽卡、养成、存档
npm run sim       # 全章自动模拟，检查不同队伍的胜率与星章
npm run qa        # 用真实 UI 跑一遍：抽卡、编队、升级、战斗、结算、刷新读档
```

`npm run qa` 需要 macOS 上的 Google Chrome，并会使用 `/tmp/ta-cdp-profile` 作为隔离的浏览器 profile。

## 设计备注

- **为什么用「标签配方」而不是自由演算**：配方能教学、能预告、能平衡，同时保留「抽到谁能凑出哪些定理」的收集深度。标签对是无序的，但要求两名不同学者，避免单角色自循环。
- **为什么是 3 行动力**：两张公式合成定理（2 点）+ 一张公式或一次公理（2 点，需取舍），让每回合都有「排序」而不是「点最大数字」。
- **为什么定理伤害无视防御**：定理是这套战斗的节拍器，也是 Boss 护盾的唯一解。普通公式提供稳定输出，定理提供破局。
- **平衡基准**：初始三人 Lv.18 + 一破可三星通过 1-10；Lv.15 无突破则可二星通过。欧拉/拉马努金/诺特这类成型队伍会明显更快。详细数据见 `test/sim.js` 输出；完整设计规格见 [docs/design-spec.md](docs/design-spec.md)。
- **非目标**：本 Demo 不含 PvP、活动轮换、剧情演出、多语言与内购；存档为单槽本地存档。
