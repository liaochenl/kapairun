# 《真理学院》设计规格

- 日期：2026-10-17
- 类型：单机 PVE 收集养成抽卡 + 回合制战斗
- 平台：桌面浏览器（Chrome / Safari），纯 HTML/CSS/JS，零依赖，`file://` 可玩
- 首版范围：第一章「悖论裂缝」，10 关，8 名学者
- 明确非目标：Roguelike、PvP、活动轮换、内购、多语言

## 1. 目标与体验

玩家扮演真理学院新任「求证者」。康托尔失踪后，定理被悖论侵蚀；玩家用「讲义」召回历史中的学者投影，让公式与公式接续成定理，逐关修复证明。

成功标准：

- 新玩家在 1 分钟内理解「3 点行动力、公式、接续」；
- 老玩家会主动规划本回合的公式顺序，为下一条定理留牌；
- 抽到新学者会改变「能凑出哪些定理」，而不只是数值；
- 单次会话 10–20 分钟，首章 1.5–2 小时；
- 无死锁、无卡死、刷新后进度保留。

## 2. 核心循环

```
推课程 → 获得 灵感 / 讲义 / 手稿
   ↓                 ↓
抽新学者 ←──── 升级、突破、顿悟
   ↓
组 3 人队，凑出更多定理配方
   ↓
挑战更难的课程与 Boss
```

## 3. 战斗

### 3.1 基础

- 3 名学者上场，每回合共享 **3 点行动力（AP）**。
- 公式消耗 1 AP，公理消耗 2 AP。
- 每张公式每回合限用一次；公理使用后进入 3 回合冷却。
- 敌方意图全程可见；玩家结束回合后，所有敌人依次行动。
- 失败无惩罚，可直接重试；已发现的定理会记录。

### 3.2 公式、标签与定理

每张公式有且只有一个标签（10 种：极限、级数、同余、归纳、对称、公理、作图、坐标、比例、概率）和一个方法（演绎、计算、构造）。

同一回合内，若连续使用的两张公式来自**不同学者**，且它们的标签组成某条已知配方，则触发「定理」：

- 定理不消耗 AP，立即结算；
- 定理伤害为「真理」伤害：无视防御与方法抗性，可削减悖论护盾；
- 每条定理每回合最多触发一次；
- 首次触发写入图鉴。

标签对是无序的；两名不同学者的限制避免单角色自循环。

### 3.3 公理

每名学者有 1 条专属公理，2 AP、冷却 3 回合。公理不参与定理配方，使用后会清空当前演算链。

### 3.4 方法克制

- 敌人的「弱点方法」：对应公式伤害 ×1.5；
- 敌人的「抗性方法」：对应公式伤害 ×0.7；
- 定理伤害不受弱点/抗性影响。

### 3.5 状态

| 状态 | 类型 | 效果 |
|---|---|---|
| 破绽 | 负面 | 受到伤害提高（默认 30%） |
| 昂扬 / 气馁 | 正面 / 负面 | 攻击 ±25% |
| 稳固 / 松动 | 正面 / 负面 | 防御 ±25% |
| 讲台 | 正面 | 敌人单体攻击优先指向该学者 |
| 失语 | 负面 | 无法使用公理 |
| 灵光 | 正面 | 下一张公式不消耗 AP |
| 澄明 | 正面 | 免疫新的负面状态 |
| 矛盾 | 持续 | 回合结束时受到伤害 |
| 蓄势 | 敌方 | 下次攻击威力提高 |

防御采用乘法减伤：`伤害 × 100 / (100 + 防御 × 2.5)`，避免高防完全免疫。

### 3.6 敌人与 Boss

- 普通敌人有 HP、攻击、防御、弱点、抗性、意图循环。
- 特殊被动：
  - 空集之影：每回合第一次受伤被闪避；
  - 无穷递归：死亡后以 40% 生命复活一次。
- Boss 罗素悖论：
  - 初始 60 点「悖论护盾」；护盾存在时普通公式伤害减半，只有定理能削减护盾；
  - 护盾碎裂时附加破绽；
  - HP ≤ 50% 进入第二阶段：攻击 +20%，补充 40 点悖论护盾，意图组更换；
  - 第二阶段有全队破绽与更高倍率的 AoE。

### 3.7 胜负与星章

- 全部敌人被击败：胜利。
- 全部学者倒下：失败，无奖励，但记录本局发现的定理。
- 星章：通关 1 星；无人倒下 +1 星；在关卡指定回合数内完成 +1 星。
- 首通发放首通奖励；重复通关发放重复奖励；每颗新星章额外发放灵感。

## 6. 抽卡与养成

### 6.1 抽卡

- 常驻池，单抽 160 灵感，十连 1600 灵感。
- 概率：SSR 3% / SR 17% / R 80%。
- 十连保底：至少一名 SR（若前 9 抽均 R，第 10 抽强制 SR）。
- SSR 硬保底 40 抽；从第 30 抽起，每抽 SSR 概率 +5%。
- 重复学者转为「顿悟」，最多 5 层；每层 +6% 生命/攻击/防御。满层后返还灵感（SSR 600 / SR 200 / R 80）。
- 无内购；灵感来自首通、星章与重复课程。

### 6.2 等级与突破

- 等级 1–30；上限由突破阶数决定：0 破 15 级、1 破 25 级、2 破 30 级。
- 升级消耗讲义：`10 + 当前等级 × 3`。
- 突破消耗手稿 + 讲义：0→1 需 2 手稿 + 150 讲义；1→2 需 4 手稿 + 300 讲义。
- 突破后全属性 ×1.10（每阶）。

## 8. 视觉与界面

- 深墨绿黑板、白色粉笔字、金色高亮；木框与粉笔灰纹理全部用 CSS/SVG 生成。
- 字体使用系统中式衬线/楷体与数学字体，不加载网络字体。
- 8 名学者与 10 名敌人各有手绘感 SVG 纹章，不依赖图片资源。
- 屏幕：主页、课程表、编队、召唤、图鉴（学者/定理/悖论）、学者详情、战斗、设置。
- 战斗布局：敌方区 / 演算链 / 我方三人 / 技能面板 / 右侧行动力、可续接定理、课堂记录。
- 动画：定理成立横幅、粉笔尘粒子、伤害数字、Boss 阶段横幅；可在设置中关闭。
- 音效：WebAudio 合成的点击、粉笔、命中、治疗、定理、胜负与抽卡音；可在设置中关闭。

## 9. 技术架构

- `rng.js`：mulberry32，可复现随机。
- `data.js`：所有静态内容，id 引用。
- `battle.js`：纯战斗引擎，不依赖 DOM；状态可序列化；导出 `createBattle / useFormula / useAxiom / endTurn / getComboOptions` 等。
- `meta.js`：档案、抽卡、等级、突破、关卡结算、存档。
- `ui.js`：单页渲染、事件委托、动画、音效、路由。
- `main.js`：启动。
- 存档键：`truth_academy_save_v1`；单槽；自动保存。
- 无 ES module，保证 `file://` 双击可玩。

## 10. 平衡与验收

自动模拟（`npm run sim`）以初始三人组、抽取队伍、欧拉/拉马努金/诺特队伍分别跑全章：

- 初始三人组 Lv.15（无突破）可在约 18 回合二星通过 1-10；
- 初始三人组 Lv.18 + 一破可三星通过 1-10；
- 成型队伍明显更快，但并非必需抽到 SSR；
- 全部 10 关在模拟中均可通关，无死锁。

验收：

- 规则测试 23 条全部通过；
- 浏览器验收脚本可在真实 UI 中完成抽卡、编队替换、升级、战斗、定理合成、胜负结算、刷新读档；
- 控制台无报错；
- 1280×800 与 1024×700 下主流程可操作（小屏内容可滚动）。

## 11. 非目标

不实现 PvP、排行榜、活动轮换、剧情演出、多语言、内购、多存档槽。首章结束后提示「下一站，无穷」，为后续扩展留钩子。
